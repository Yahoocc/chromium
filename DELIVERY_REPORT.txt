## 🔍 工作原理

### 标记阶段
```
数据源 → __setTaint__(data, 1) → 内部污点位图
```

### 传播阶段
```
污点字符串 → 操作(concat/slice/etc) → 新字符串继承污点
```

### 检测阶段
```
污点字符串 → eval/Function/innerHTML → LogIfTainted()
                                        ↓
                                   TaintListener触发
                                        ↓
                                   记录日志/报警
```

## 💡 使用示例

### JavaScript中使用

```javascript
// 1. 标记污点
var userInput = getUrlParam('code');
userInput.__setTaint__(1);

// 2. 污点自动传播
var command = 'exec(' + userInput + ')';

// 3. 到达sink时自动报警
eval(command);  // 触发TaintListener
```

### C++中使用

```cpp
// 1. 标记污点
Handle<String> str = factory->NewStringFromUtf8(...);
SetTaintStatus(*str, 0, TaintType::TAINTED);

// 2. 检测污点
TaintType status = GetTaintStatus(*str, 0);

// 3. 记录到sink
LogIfTainted(str, TaintSinkLabel::JAVASCRIPT, 0, isolate);
```
